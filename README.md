# 🤫 Silent Poker Accountant

سیستم حسابداری حرفه‌ای و خاموش برای مدیریت بازیکنان پوکر و محاسبات خودکار.

---

## 🎯 ویژگی‌ها

✅ **صفحه ورود حرفه‌ای** - انتخاب 4 ادمین با رنگ‌های مختلف  
✅ **داشبورد پیشرفته** - آمار کامل و گزارشات  
✅ **مدیریت بازیکنان** - افزودن و مدیریت بازیکنان  
✅ **5 روش شارژ** - USDT, TRX, ریالی, بدهی, پرداخت بدهی  
✅ **سوابق کامل** - تاریخچه تمام تراکنش‌ها  
✅ **رنگ‌های قابل تغییر** - 4 تم مختلف برای ادمین‌ها  
✅ **Responsive Design** - موبایل و دسکتاپ  

---

## 🚀 نحوه استفاده

### 1️⃣ **نصب و اجرا**
```bash
# فولدر را در VS Code باز کن
code .

# یا فایل index.html را با مرورگر باز کن
```

### 2️⃣ **ورود**
```
ادمین: admin1 / admin2 / admin3 / admin4
رمز: pass1234
```

### 3️⃣ **رنگ‌های مختلف**
- **ادمین 1** - سیان (آبی روشن)
- **ادمین 2** - قرمز
- **ادمین 3** - فیروزه
- **ادمین 4** - طلایی

## 💾 ذخیره‌سازی

- سوابق تراکنش‌ها
- شارژ و بدهی
